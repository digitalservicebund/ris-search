# RIS Portal API-Docs

Static documentation site for the RIS portal public API, built with [VitePress](https://vitepress.dev/).

Covers basics about the API and links to the swagger documentation.

VitePress is pinned to a 2.0 prerelease and excluded from Dependabot, because
each alpha has carried breaking changes. Bump it deliberately, and check the
[changelog](https://github.com/vuejs/vitepress/blob/main/CHANGELOG.md) first.

## Setup

```sh
pnpm install
```

## Run locally

```sh
pnpm dev
```
